## Proposed lessons for canon (candidates only — NOT written here)

`/pharn-dev-review` declares no `.dev/memory-bank/**` path and cannot write canon. Both candidates below
were **observed live this run** (P7 — real, not hypothetical) and are offered for a separate,
human-gated `/pharn-dev-memory-promote`.

### Candidate A — "L5's remedy is itself a portability trap: `xargs -a` is GNU-only"

**Lesson (draft).** L5 prescribes `xargs` to expand a gate's file list safely; L12 records re-hitting
L5's zsh word-split. This run hit a **third** variant — **inside the remedy**: `xargs -a <file>` is a
**GNU extension** that macOS/BSD `xargs` rejects (`xargs: invalid option -- a`), so the _gate command
itself_ failed and its exit code was captured as the gate result, recording a **false red baseline**
(`tests: 1`) on a provably green repo. Equal at base and head, it would have been classified
`pre-existing` and would have **masked** a real tests-gate regression — L5's documented failure mode,
reached through L5's own fix. Remedy: expand via **stdin** (`xargs node --test < list`), and treat a red
baseline on a known-green repo as a signal to **investigate the harness**, never to accept.

**Provenance.** feature `applied-lessons`; base `de83cbb`; surfaced by
`.dev/features/applied-lessons/REGRESSION.md` (defect 1), reproduced live before and after the fix.
Complements L5 and L12.

### Candidate B — "`check-regress scope` tests changed-since-base, not written-by-the-build"

**Lesson (draft).** `check-regress.mjs scope` computes
`escaped = inside.filter(f => !matchesAny(f, declared))` (`:192`) over `git diff <base>`, with no
exclusion for other pipeline stages' own artifacts or for human-authored trusted-doc edits. With
`base = HEAD` on a working-tree dogfood, **every** sibling stage's output lands in `inside` and reads as
"the build escaped its `## Files`". This run it emitted two **blocking** fix#7 findings that were both
provably false: `GRILL.md` (written by `/pharn-dev-grill` under its own Step-0 scope) and
`pharn/ARCHITECTURE.md` (human-authored; the agent **cannot** write it — `protect-trusted-paths.cjs`
denies at exit 2, verified live). A **changed-since-base** test is being read as a
**written-by-the-build** test — two different questions, and the fail-closed one cries wolf on exactly
the correct, designed workflow. Remedy: exclude the feature's own `.dev/features/<name>/**` pipeline
artifacts and the hook-protected trusted docs from the escape set, or derive "written by the build" from
the build's actual scope record rather than from the diff.

**Provenance.** feature `applied-lessons`; base `de83cbb`; surfaced by
`.dev/features/applied-lessons/REGRESSION.md` (defect 2), with the fix#2 hook denial verified live as
the disproof. Complements L3/L7/L8 (the `writes:`/scope subsystem) and L5 (orchestration vs floor).
