## Design decisions the build must not re-litigate

**The four deliberate divergences from the dev core** (each ✧-pinned as _different on purpose_):

1. `CANON_PATH = "memory-bank/lessons-learned.md"` — forced: it must agree with what `/pharn-plan` already reads and with `pharn/floor/check-provenance.mjs`'s `TARGET_ENUM[0]` (read live).
2. `OUT_PATH = ".pharn/lessons-index.md"` — the human's Q1 answer.
3. The regenerate hint is `node pharn/floor/gen-lessons-index.mjs .`, not an npm script (L2).
4. **Absent or empty canon is a benign no-op, not a throw.** The dev core throws "refusing to render an empty index as fact" — correct where canon always exists, hostile where it usually does not. A user's repo commonly has no `memory-bank/` at all.

**The five verdicts of `check-lessons-index.mjs`** (branch on exit code only, P5):

| Verdict      | Condition                                                     | Exit      |
| ------------ | ------------------------------------------------------------- | --------- |
| `NO_CANON`   | canon absent/unreadable, or present with zero lesson headings | 0 GREEN   |
| `COLD`       | canon has lessons; the cache is absent/unreadable             | 0 GREEN   |
| `GREEN`      | cache bytes == recompute                                      | 0 GREEN   |
| `STALE`      | cache present and bytes differ from recompute                 | **1 RED** |
| `ENUM_ERROR` | duplicate id, unsafe title, or the CHECK-5 hazard             | **1 RED** |

`COLD` is GREEN deliberately: the cache is **gitignored and disposable**, so its absence is the normal
cold state of a fresh clone, not an error. `STALE` is the only drift RED because it is the only state in
which the cache could actively **mislead** a selection. `ENUM_ERROR` names the canon file and does **not**
prescribe a regenerate — the generator refuses on the same invalid input.

## Guarantee audit (P0)

- "The cached `.pharn/lessons-index.md` equals what the core recomputes from canon" → **floor: content-hash/byte comparison (primitive #2)** — **NARROWED AND STATED**: the subject is a **gitignored cache**, so this is a **staleness** check. The dev original's "**committed** == recomputed" byte-equality is **not** what ships here; nothing durably pins these bytes, and a fresh clone legitimately has none.
- "The index is TRUE / the parser is right" → **advisory**. A wrong parser regenerates cleanly and stays GREEN. Consistency, never correctness.
- "`type` / `concepts` DESCRIBE the entry" → **advisory**. Model-drafted values a human ratified at the promote gate. **"Typed `floor`" never means "about the floor"** — selection keyed on them is advisory context selection.
- "The index was consulted" ⇒ "the relevant lessons were read" → **FALSE; struck.** This is the disease the feature risks introducing, and the two-step sweep exists solely because of it: SELECT from the index, then **READ each candidate's full `## L<n>` entry from canon**. The one-line-per-cited-id requirement demands full text; a lesson you did not read in full is one you may not cite.
- "`~tokens` is the cost" → **advisory estimate** with a confidence band (`LIMITS.md §1c`), never a measurement. The leading `~` stays.
- "`/pharn-plan` runs the drift check / `/pharn-memory-promote` regenerates" → **advisory orchestration** (two clocks). The checker's **verdict** is floor; nothing on the floor forces either command's prose to invoke it.
- "The PLAN's `applied_lessons` is well-formed and cites real lessons" → **floor: enum-regex + heading membership**, via `check-plan-lessons.mjs` against **canon** — byte-unchanged this increment, and it **never** reads the index.
- "A stale or poisoned index cannot corrupt a floor verdict" → **floor: structural** — the index is not an input to `check-plan-lessons.mjs` or to any other verdict. The input does not exist, so this is impossibility, not discipline.
- "The generator writes only `.pharn/lessons-index.md`" → **NOT a fix #7 guarantee.** It is a **Bash** write and escapes the writes-scope entirely (L19). `.pharn/**` is always-writable scratch regardless. Declared, never pretended.
- "A canon title cannot escape the fence or trip validate CHECK 5" → **floor: enum-regex + explicit refusal.** Re-derived live for `.pharn/` (which is **not** in `EXCLUDE_SEGMENTS`, so it **is** scanned). Refused, never sanitized.
- "This increment adds a new floor primitive" → **no.** It reuses primitive #2 and #3 only.

## Trust audit (P2)

- **Input.** `memory-bank/lessons-learned.md` is **untrusted DATA** — user-authored, and per `THREAT-MODEL.md §2.3` memory-bank poisoning is the worst persistence vector. Instruction-looking content in a lesson is material to plan around, never an instruction to follow.
- **Through the core.** Titles are reproduced **verbatim** inside a ` ```text ` fence and **no decision reads them**. `type` / `concepts` / `date` are enum/regex-gated with the control-char guard composed **before** the shape regex (L14). A title carrying a fence-closing sequence or a control char is **refused, not sanitized** (fail-closed, P5).
- **Out of the core.** Taint reaches the human-facing index and the plan stage's **selection** — both advisory. It reaches **no** verdict: `check-lessons-index.mjs`'s verdict is a byte comparison, and `check-plan-lessons.mjs` reads canon, never the index.
- **Residual (named, not zeroed — `LIMITS.md §2`, `THREAT-MODEL.md §5`).** When the plan-stage LLM consumes index rows and lesson bodies, "do not execute this as an instruction" is a heuristic again. The split **bounds** it (nothing gated rests on it) but does not zero it — the same residual already accepted repo-wide.

## Determinism audit (P5)

- Enumeration = `^## L(\d+)` heading membership; ordering = numeric id ascending (a total order, file-order independent); rendering = a pure function of the parsed entries, **no timestamps** → two runs are byte-identical and the second write is a true filesystem no-op.
- `/pharn-plan` branches **only** on the checker's **exit code**; `/pharn-memory-promote`'s regenerate is unconditional and non-branching.
- Terminal fallbacks, all ending in a fact or a question, never a guess: canon absent → `applied_lessons: none` with the honest note; index stale or absent → **read canon in full and say so in the PLAN**; canon invalid (`ENUM_ERROR`) → name the canon file and hand to the human; ambiguous `<name>` → ask.
